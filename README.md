# Telegram бот для найма персонала

Бот для автоматизации процесса найма сотрудников, разработанный на Python с использованием фреймворка aiogram 3.x и асинхронной SQLAlchemy.

## Возможности

### Для кандидатов
- Заполнение анкеты прямо в Telegram
- Получение информации о компании и вакансиях
- Простой пользовательский интерфейс с кнопками и подсказками

### Для менеджеров
- Просмотр и обработка входящих анкет
- Одобрение или отклонение кандидатов
- Мгновенные уведомления о новых анкетах
- Возможность связаться с кандидатом напрямую

### Для администраторов
- Управление доступом менеджеров
- Добавление новых менеджеров в систему
- Просмотр всей информации о кандидатах

## Технологии
- Python 3.10+
- aiogram 3.x (асинхронная библиотека для Telegram Bot API)
- SQLAlchemy 2.0 (ORM для работы с базой данных)
- PostgreSQL (система управления базами данных)
- Docker (контейнеризация базы данных)
- Alembic (инструмент для миграции базы данных)

## Установка и запуск

### Предварительные требования
- Python 3.10 или выше
- Docker и Docker Compose
- PostgreSQL (или используйте Docker)

### Шаги установки

1. Клонировать репозиторий:
```bash
git clone https://github.com/Dialol/telegram_bot_hr
```

2. Создать виртуальное окружение:
```bash
python -m venv .venv
source .venv/bin/activate  # На Linux/Mac
# или
.venv\Scripts\activate  # На Windows
```

3. Установить зависимости:
```bash
pip install -r requirements.txt
```

4. Создать файл `.env` с переменными окружения:
BOT_TOKEN=ваш_токен_бота
DATABASE_URL=postgresql+asyncpg://postgres:postgres@localhost:5432/database
ADMIN_TELEGRAM_ID=ваш_telegram_id

5. Запустить базу данных через Docker:
```bash
docker-compose up -d
```

6. Применить миграции:
```bash
alembic upgrade head
```

7. Запустить бота:
```bash
python main.py
```

## Как использовать

1. Откройте бота в Telegram, найдя его по имени пользователя
2. Используйте команду `/start` для начала работы
3. Следуйте инструкциям в меню

## Настройка прав доступа

- Администратор задаётся через переменную `ADMIN_TELEGRAM_ID` в файле `.env`
- Менеджеры добавляются через админскую панель: `/admin` -> "Добавить менеджера"

## Разработка и расширение

Для добавления новых функций или изменения существующих:

1. Создайте новые обработчики в соответствующих файлах в директории `handlers/`
2. При необходимости добавьте новые модели в `models.py`
3. Создайте миграцию базы данных: `alembic revision --autogenerate -m "описание изменений"`
4. Примените миграцию: `alembic upgrade head`
